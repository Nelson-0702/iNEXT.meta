# iNEXT.meta

The `iNEXT.meta` package provides tools for meta-analysis of coverage-standardized taxonomic (TD), phylogenetic (PD), and functional (FD) diversity between two treatments across multiple studies or sites.

Three main functions, `DataInfobeta3Dmeta()`, `iNEXTbeta3Dmeta()`, and `ggiNEXTmeta()`, are provided for summarizing data information, performing fixed-effect meta-analysis of standardized diversity and dissimilarity measures, and visualizing the results using forest plots.

Two example datasets, `Spider` (abundance data) and `Hoverfly` (incidence data), along with their corresponding phylogenetic trees and species pairwise distance matrices, are included to demonstrate the package's functionality.
